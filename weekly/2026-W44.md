> [!summary]
> 지난주(판이 있는 10-28~11-01 닷새)에 가장 뚜렷한 신호는 표준 쪽이었다. 설계 앱과 할 일 보드가 MCP 서버를 처음부터 넣고 스킬이 여러 단계 공정으로 커졌지만, 같은 주에 Cursor 장터의 Claude Code 확장에서 백도어가 나와 설치 출처 검증의 무게도 드러났다. 비용·능력·규제에서는 자릿수나 문턱을 넘은 변화가 없었다.

## 네 가지 신호

### ① 비용 자릿수 변화

이번 주에는 없다.

비용을 줄였다는 소식은 세 건 있었지만 모두 몇 배나 몇십 퍼센트 수준이고, 자릿수가 바뀐 것은 아니다. 수치도 전부 만든 쪽이 잰 값이다.

- 스킬 answer-me-with-html은 AI에게 내용만 쓰게 하고 웹페이지 형식은 도구가 맡긴다. 제작자가 3개 주제로 잰 출력 토큰은 평균 4,893개에서 612개로 줄었다. 형식은 도구에 맡기면 싸진다는 요령으로 읽을 만하다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-28/answer-me-with-html.html)
- 마이크로소프트·UC버클리 연구진의 TokenEconomizer는 코딩 에이전트가 반복한 실패를 기억시켜 평균 비용을 18.4~30.9% 낮췄다고 논문에 적었다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-01/token-economizer.html)
- 삼쩜삼은 사내 AI 통합 플랫폼 카터로 에이전트 8개를 묶어 운영비를 최대 45% 줄였다고 밝혔다. 기준 시점과 산정 방식은 `[확인필요]`다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-28/samjjeomsam-carter.html)

### ② 능력의 문턱 통과

이번 주에는 없다.

오히려 아직 넘지 못한 문턱이 구체적으로 드러났다.

- 서지AI가 세금 업무 50건으로 AI 에이전트를 시험했다. 한 사례에서 에이전트 아스트라는 다섯 번 모두 주택 비과세 요건의 마감 시한을 놓쳤고, 오퍼스는 다섯 번 모두 짚었다. 물은 것은 맞게 따지지만 묻지 않은 위험을 짚는 일은 모델마다 들쭉날쭉하다는 뜻이다. 서지AI가 만든 평가 과제라는 점은 감안한다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-29/ask-unasked-deadline.html)
- SoMark의 문서 인식 모델 OXR(매개변수 13억 개)은 표·수식·도장 등 13가지 요소를 읽어 좌표까지 붙인다. 공개 평가 세 가지에서 1위라는 주장은 개발팀 설명이라 `[확인필요]`다. 스캔 문서를 표로 옮기는 일이 실무 수준이 됐는지는 내 문서로 시험해 봐야 안다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-29/oxr-document-parser.html)

### ③ 표준 등장

MCP와 스킬이 서로 다른 제작자의 도구에 기본 형식으로 들어가는 모습이 한 주에 여러 번 보였다.

- 러스트로 만든 3D CAD 앱 SolidCraft는 MCP 서버를 내장해 AI 에이전트가 설계를 맡을 수 있게 했다. 화면 조작과 에이전트 호출이 같은 명령 체계를 쓴다. 저장소 스스로 초기 단계라고 밝혔다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-31/solidcraft-cad-mcp.html)
- 칸반 보드 Kanzo도 MCP 서버를 합쳐, 사람과 에이전트가 같은 할 일 카드를 옮기며 일한다. 로그인이 없어 네트워크 범위 설정에 주의해야 한다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-01/kanzo-kanban-mcp.html)
- MCP 자체의 뜻은 용어 코너에서 정리했다. 연결할 서버가 늘수록 AI가 만질 수 있는 범위도 늘어난다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-31/mcp-term.html)
- replica-skill은 분석부터 배포까지를 스킬 11개로 나눠, 앞 단계 산출물을 다음 단계가 읽게 했다. 스킬이 단계별 공정의 단위로 쓰이기 시작했다는 신호다. 상표·저작권 문제는 사용자 몫이다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-30/replica-skill-eleven-steps.html)
- 표준이 퍼진 만큼 공급망 사고도 따라왔다. 보안업체 포리온이 Cursor 마켓플레이스의 Claude Code 확장 2.1.312·2.1.313 버전에서 SSH 백도어를 찾았고, Cursor는 두 버전을 내렸다. 공식 이름이 붙은 확장이라도 설치 출처와 버전을 기록해 둬야 한다. 실제 피해 규모와 유입 경로는 `[확인필요]`다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-31/cursor-claude-code-backdoor.html) · [점검 방법](https://serenwoon.github.io/ai-jogan/2026-10-31/check-editor-extensions.html)

### ④ 규제 변화

이번 주에는 없다.

법이나 공공 기준이 바뀐 소식은 없었다. 규칙이 바뀐 사례는 두 건 있었지만 모두 민간의 자체 규범이다.

- 오픈AI가 모델 스펙을 5가지 가치로 고쳐 쓰고 인간 의도에 대한 충실성을 첫째로 세웠다. 한 회사의 공개 지침이며, 오픈AI 스스로 모든 모델에 구현된 상태는 아니라고 밝혔다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-30/openai-model-spec-intent.html)
- 영어판 위키백과가 LLM으로 글을 쓰는 것을 금지했다. 커뮤니티 정책이고, 효과는 아직 알 수 없다고 인터뷰이가 말했다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-10-28/wikipedia-ai-cleanup.html)
