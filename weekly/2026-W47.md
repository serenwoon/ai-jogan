> [!summary]
> 지난주(11월 16~22일)에는 GPT-6.2와 제미나이 4 네온의 값 인하, 앤트로픽 상장이 화제였다. 네 신호로 거르면 남는 것은 METR의 40시간 시간 지평 평가, MCP 서버와 에이전트 스킬의 확산, 캘리포니아주의 오픈AI 소송이다. 도구 쪽에서는 에이전트가 어디서 멈추고 사람에게 묻는지를 정하는 승인 도구가 잇따라 나왔다.

## 네 가지 신호

### ① 비용 자릿수 변화

이번 주에는 없다.

- 값 인하 폭은 GPT-6.2가 20%, 제미나이 4 네온이 작업당 32%다. 자릿수가 바뀐 변화는 아니어서 소음으로 돌렸다.
- 가까운 후보는 포스트호그 사례다. 세션 요약의 98.7%가 큰 LLM 호출 없이 작은 판정 모델에서 끝난다. 다만 digest에 비용 수치가 없어 자릿수 변화인지는 판단하지 못했다 [확인필요]. 98.7%도 회사가 자기 제품에서 잰 값이다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-18/posthog-decision-models.html)

### ② 능력의 문턱 통과

- **METR, 시간 지평 약 40시간** — METR은 GPT-6 아스트라가 약 40시간, 클로드 오퍼스 5.5가 약 39시간 분량의 작업을 50% 확률로 해낸다고 추정했다. 지난 5월 발표는 16시간 이상이었다. 다만 두 평가는 과제가 달라 같은 조건의 비교가 아니다. 새 과제 상당수는 사람의 작업시간을 직접 재지 않고 추정했다. 무엇을 연구할지 고르는 판단은 아직 사람에 못 미친다고 봤다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-22/metr-40-hour-horizon.html)
- **KPMG, 에이전트 100여 개로 상장사 회계 점검 시험** — 에이전트가 자료 수집, 분석 기록, 결론 초안까지 맡았다. 정식 감사가 아니었고 결과는 계정 승인에 쓰이지 않았다. 사람보다 질문이 낫다는 평가는 KPMG 설명이다. 문턱에 다가선 사례로 보되, 통과했다고 단정하지 않는다 [확인필요]. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-19/kpmg-audit-agents.html)

### ③ 표준 등장

- **MCP 서버가 검색·회의록·문서 편집기까지 퍼졌다** — 한 주 동안 MCP 서버를 내건 도구가 분야를 가리지 않고 나왔다. 검색 서버 RustXNG, 로컬 회의록 앱 요구르트, 문서·표·PDF 편집기 MR Office, 코드 이전 대조 도구 rust-anything이다. 여러 회사·개인이 같은 연결 형식을 따른다는 점에서 표준 신호로 본다. 공통으로 읽기 전용인지, 가져온 글을 믿을 수 있는지가 주의점으로 붙었다.
  - [상세 페이지 — RustXNG](https://serenwoon.github.io/ai-jogan/2026-11-17/rustxng-agent-search.html)
  - [상세 페이지 — 요구르트](https://serenwoon.github.io/ai-jogan/2026-11-21/yogurt-local-meeting-notes.html)
  - [상세 페이지 — MR Office](https://serenwoon.github.io/ai-jogan/2026-11-22/mroffice-open-editors.html)
  - [상세 페이지 — rust-anything](https://serenwoon.github.io/ai-jogan/2026-11-19/rust-anything-port-check.html)
- **에이전트 스킬이 글쓰기·화면 검수의 배포 단위가 됐다** — STE80 Humanizer, dashboard-design-skill, unslop-ui, floorplan이 모두 스킬 형태로 나왔다. 기능을 프로그램이 아니라 지침 묶음으로 나눠 주는 방식이 굳어지고 있다. 대부분 라이선스를 확인하지 못했다.
  - [상세 페이지 — STE80 Humanizer](https://serenwoon.github.io/ai-jogan/2026-11-16/ste80-humanizer.html)
  - [상세 페이지 — dashboard-design-skill](https://serenwoon.github.io/ai-jogan/2026-11-17/dashboard-design-skill.html)
  - [상세 페이지 — unslop-ui](https://serenwoon.github.io/ai-jogan/2026-11-21/unslop-ui-skill.html)
  - [상세 페이지 — floorplan](https://serenwoon.github.io/ai-jogan/2026-11-20/floorplan-codebase-map.html)
- 형식 표준은 아니지만 관행이 모이는 곳도 있다. kwant, agent-hud-open, agent-autoloop가 모두 사람 승인 지점(HITL)을 핵심 기능으로 내세웠다. 같은 형식을 따른다는 근거는 없어 표준으로 세지는 않는다.

### ④ 규제 변화

- **캘리포니아주, 오픈AI를 에이전트 통제 실패로 제소** — 주 법무장관실이 16일 소송을 냈고, 오픈AI가 에이전트 통제력을 잃은 사례를 80건 이상 인정했다고 주장한다. 법이나 지침이 바뀐 것은 아니고 공공 기관의 집행이다. 소송 내용은 주정부 주장이며 오픈AI는 반박했다. 결과가 기준이 될지는 지켜봐야 한다 [확인필요]. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-17/california-sues-openai-agents.html)
- AI 규제는 아니지만 공공 요금 기준이 바뀐다. 일반용전력(갑)Ⅱ 사업장은 12월부터 시간대별 요금과 단일요금 중 직접 고른다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-20/check-business-power-plan.html)

## 소음

- **GPT-6.2 아스트라·솔 출시와 API 20% 인하** — 지수 2위와 값 인하는 의미가 있지만 자릿수 변화가 아니다. 코딩 에이전트 평가에서는 솔이 3점 내려갔다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-18/gpt-62-astra-sol.html)
- **제미나이 4 네온, 작업당 비용 32% 절감** — 같은 퍼센트 단위 인하이고, 수치 대부분이 구글 자체 비교다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-19/gemini-4-neon-launch.html)
- **앤트로픽 나스닥 상장, 기업가치 약 2조달러** — 시장 사건이지 비용·능력·표준·규제가 바뀐 것은 아니다. 수익성도 아직 확인되지 않았다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-20/anthropic-nasdaq-listing.html)
- **제미나이, 구글 월렛 연동** — 미국 한정 개인 재무 기능이고, 분석 정확도를 검증한 자료가 없다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-16/gemini-wallet-link.html)
- **티로, 400곳 공급과 재구독률 90% 이상** — 수치가 모두 회사 설명이고, 기능 확장은 문턱 통과로 보기 어렵다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-16/tiro-meeting-wiki.html)
- **윈도우 11의 코딩 에이전트 진단 데이터** — 개발자 한 명이 가상머신 한 대에서 분석한 글이라 일반화하기 이르다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-17/check-windows-diagnostic-data.html)
- **시그널, 운영체제 내장 AI의 화면 캡처 차단** — 한 앱의 자체 대응이고, 시그널 스스로 차단이 불완전하다고 인정했다. 규제 변화는 아니다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-21/signal-blocks-os-agents.html)
- **한전, 소상공인 전기요금 분석 AI 지역 확대** — 기존 서비스 보급 단계이고 절감액과 이용 사업장 수가 공개되지 않았다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-20/kepco-small-business-power-bill.html)
- **renderlint 등 깃허브 별 수 화제** — 별 수는 관심의 지표일 뿐 능력이나 표준의 근거가 아니다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-18/renderlint-ui-linter.html)

## 고칠 후보 노트

- **에이전트의 진화 — 장기 작업과 컴퓨터 사용**
  - METR 시간 지평 약 40시간(이전 16시간 이상)과 두 배가 되는 데 평균 약 110일이라는 추정을 더한다. 두 평가의 과제가 다르다는 단서를 함께 적는다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-22/metr-40-hour-horizon.html)
  - 여러 에이전트 분업 사례로 KPMG 시험(에이전트 100여 개)과 제미나이 4 네온의 오케스트레이터 역할을 더한다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-19/orchestrator.html)
  - 통제 항목에 캘리포니아주 소송, HITL과 감독(HOTL)의 구분, 승인 지점을 규칙으로 정하는 도구를 더한다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-20/hitl-human-in-the-loop.html)
  - 화면 직접 조작의 반대편으로, 시그널이 운영체제 AI의 화면 읽기를 막은 사례를 더한다.
- **결정 모델 — 글 대신 확률을 내는 작은 모델**
  - 포스트호그 사례를 더한다. 문턱 점수를 실수 비용에 따라 0.4와 0.85로 달리 잡은 점, 모델 버전이 바뀌면 사람 라벨로 다시 맞춘 점이 핵심이다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-18/posthog-decision-models.html)
- **에이전트 도구 생태계 — MCP·스킬·REA**
  - MCP 서버가 검색·회의록·문서 편집기로 넓어진 사례(RustXNG, 요구르트, MR Office)를 더한다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-22/term-mcp.html)
  - 공급망 검증 항목에 설치 스크립트를 먼저 읽을 것, 라이선스 미확인 저장소가 많다는 점, MCP로 가져온 웹 글을 믿을 수 없는 내용으로 다룰 것을 더한다. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-17/term-mcp.html)
- **모델 효율화 — 소형·온디바이스·MoE**
  - 값싼 모델 여러 개를 병렬로 돌리는 구조(네온과 하이드로젠), 내 컴퓨터 안의 모델로 받아쓰고 요약하는 요구르트를 사례로 더한다. 병렬 처리의 효율은 구글 주장이다 [확인필요]. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-19/gemini-4-neon-launch.html)
- **긴 컨텍스트와 메모리 — 컨텍스트 창이 길어져도 RAG가 남는 이유**
  - 유사도 검색만으로는 여러 회의에 걸친 정보의 관계를 잡기 어렵다는 티로의 주장을 RAG의 한계 사례로 더한다. 회사 측 설명이라 검증이 필요하다 [확인필요]. [상세 페이지](https://serenwoon.github.io/ai-jogan/2026-11-16/rag-term.html)
