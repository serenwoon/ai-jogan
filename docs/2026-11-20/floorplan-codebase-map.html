AI가 앱 구조를 쉬운 말로 그려 주는 지도 도구가 떴다

스킬라이선스 미확인

저장소 이름은 floorplan이다. Claude나 Codex가 코드를 읽고 부품·파일·요청의 연결을 쉬운 말로 이름 붙인 지도로 그려 준다.

floorplan은 코딩 에이전트인 Claude Code나 Codex에게 지도를 요청하면 앱 전체를 눌러서 들여다보는 도식으로 그려 준다. 결제 처리 모듈 같은 부분은 기술 용어 대신 카드 결제를 받는 부분처럼 풀어 쓴다. 코드에 박힌 비밀번호, 누구나 읽는 데이터베이스 같은 흔한 실수를 점검하는 기능도 넣었다.

왜 지금

AI의 도움으로 앱을 만든 사람이 늘면서 만든 본인도 구조를 모르는 일이 생겼다. 이 저장소는 하루 사이 별이 309개 늘었다.

내 일에 써 본다면

개발 외주사가 만든 사내 도구를 인수받는 담당자라면 인수 회의 전에 지도를 뽑아 보자. 외부 서비스와 연결된 부분만 짚어도 질문 목록이 나온다.

가져갈 점

AI가 만든 결과물은 만든 뒤의 설명 자료까지 AI에게 시켜야 맡긴 일이 끝난다. 설명이 쉬우면 검토할 사람도 늘어난다.

조심할 점

개발자용 도구여서 비개발자가 바로 쓰기는 어렵다. 라이선스는 이번에 확인하지 못했다. 점검 기능은 개발사 스스로 감사가 아닌 점검이라고 선을 그었다.
