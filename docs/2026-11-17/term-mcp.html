MCP(모델 컨텍스트 프로토콜)

AI가 검색, 파일, 일정 같은 외부 도구를 같은 방식으로 불러 쓰게 하는 공통 규격이다. 오늘 소개한 RustXNG도 이 규격으로 연결한다.

MCP는 AI 프로그램과 외부 도구 사이의 연결 규격이다. 도구 쪽이 MCP 서버를 열어 두면 규격을 따르는 AI라면 어디서든 그 도구를 쓴다. RustXNG의 검색과 페이지 읽기가 그런 도구 두 개다.

왜 지금

깃허브에 올라오는 에이전트 도구 상당수가 MCP 서버를 내세우고 있다.

내 일에 써 본다면

회의록 폴더나 일정 도구를 MCP 서버로 연결해 두면, 회의가 끝난 직후 AI에게 지난주 회의 결정 사항만 모아 달라고 시킬 수 있다.

가져갈 점

MCP 서버는 AI에게 열어 주는 문과 같다. 문마다 읽기 전용인지 쓰기까지 되는지 먼저 본다.

조심할 점

MCP 서버가 돌려준 글에 숨은 지시가 섞여 있을 수 있다. RustXNG 문서도 가져온 웹 글을 믿을 수 없는 내용으로 다루라고 안내한다.
