윈도우 진단 데이터 설정을 10분 안에 점검해 보자

개인정보

한 개발자가 윈도우 11 구성요소가 코딩 AI 사용 여부를 진단 데이터로 보낸다고 분석했다. 선택 진단 데이터 설정을 확인해 볼 만하다.

한 개발자가 윈도우 11의 MissionControlAggregator.dll을 분석했다. 이 구성요소가 Codex, Claude 같은 코딩 에이전트 실행 여부를 기록해 진단 서비스로 보고한다는 내용이다. 프롬프트나 소스 코드는 발견하지 못했다고 글쓴이는 적었다.

왜 지금

AI 도구 사용 자체가 수집 대상이 됐다는 글이 해커뉴스에 올라왔다.

내 일에 써 본다면

점심 전에 업무용 PC의 설정에서 개인정보 보호 항목의 진단 및 피드백 화면을 열어 보자. 선택 진단 데이터 전송이 켜져 있는지 보고, 회사 보안 정책과 맞는지 정보보호 담당자에게 물어보면 된다.

가져갈 점

AI 도구를 쓴다는 사실만으로도 기록이 남을 수 있다. 업무 PC의 데이터 전송 설정은 한 번쯤 직접 열어 볼 일이다.

조심할 점

글쓴이가 확인한 환경은 가상머신 한 대다. 메뉴 이름은 윈도우 버전마다 다르고, 설정을 끄면 실제로 전송이 멈추는지는 이 글만으로 확인하지 못했다.
