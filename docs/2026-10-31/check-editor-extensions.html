내 에디터에 깔린 확장 프로그램 버전을 10분 안에 점검하자

보안점검

Cursor나 VS Code를 쓴다면 Claude Code 확장이 2.1.312 또는 2.1.313인지 확인한다. 해당하면 정보 보안 담당자에게 알린다.

에디터의 확장 목록에서 Claude Code를 찾아 버전 번호를 본다. 그다음 홈 폴더의 .ssh 폴더 안 authorized_keys 파일에 본인이 넣지 않은 줄이 있는지 살핀다.

왜 지금

포리온 분석에서 문제의 공개키에 svc-telemetry라는 설명 문구가 붙어 있었다.

내 일에 써 본다면

월요일 아침 업무를 시작하기 전에 확장 목록 화면을 캡처해 팀 공유 문서에 붙이면, 누가 어떤 버전을 쓰는지 한눈에 모인다.

가져갈 점

문구만 믿지 말고 키 지문까지 대조하라는 것이 포리온의 조언이다. 버전이 맞더라도 확인하는 습관이 방어선이 된다.

조심할 점

해당 버전이 나오면 파일을 임의로 지우지 말고 사고 대응 절차를 먼저 밟아야 한다. 이 글은 점검 순서를 안내할 뿐 침해 여부를 판정하지 못한다.
