Cursor 장터의 Claude Code 확장에서 SSH 백도어가 나왔다

보안확장 프로그램

보안업체 포리온이 Cursor 마켓플레이스의 Claude Code 확장 2.1.312·2.1.313 버전에서 SSH 백도어를 찾았다. Cursor는 두 버전을 장터에서 내렸다.

포리온은 Cursor 마켓플레이스에 올라온 공식 Claude Code VS Code 확장에 악성 코드가 섞인 것을 발견했다. 코드는 확장이 로드되는 순간 실행되고, 공격자의 SSH 공개키를 사용자 계정의 접속 허용 목록에 몰래 추가한다. macOS, 리눅스, 윈도우용 설치 로직이 모두 들어 있었다.

왜 지금

Cursor가 보안 공지를 내고 영향 버전을 2.1.312와 2.1.313으로 확정했다. 포리온도 10월 31일 자로 기존 안내를 고쳤다.

내 일에 써 본다면

회사 노트북에 코딩 도구를 깔아 둔 팀이라면 월요일 업무 시작 전에 정보 보안 담당자에게 설치 버전을 물어보자. 개발자가 아니어도 문서 자동화 스크립트용으로 에디터를 쓰고 있다면 해당된다.

가져갈 점

에디터 확장은 사용자와 같은 권한으로 돈다. 공식 이름이 붙은 확장이라도 설치 출처와 버전을 기록해 두어야 사고가 났을 때 범위를 좁힌다.

조심할 점

포리온은 macOS 쪽 설정 오류로 접속 경로가 막혔을 가능성을 짚었지만, 키와 상시 실행 장치는 심긴다고 했다. 실제 피해 규모와 유입 경로는 확인하지 못했다.
