코딩 에이전트를 게임 스튜디오로 바꾸는 오픈소스 OpenGame

스킬MCP

OpenGame은 사용자의 코딩 에이전트에 게임 제작 도구와 기본 게임 25종을 붙여 준다. 하루 새 별이 1,129개 늘었다.

OpenGame은 클로드 코드나 코덱스 같은 로컬 에이전트에 연결해 아이디어 한 줄에서 게임을 만들게 하는 저장소다. 바로 해 볼 수 있는 게임 25종을 담았고, 에이전트가 쓰는 도구 12개를 MCP로 연결한다. MCP는 AI에 외부 도구를 붙이는 공통 규격이다.

왜 지금

오늘 수집 목록에서 하루 증가분이 가장 컸다. 별은 2,382개다.

내 일에 써 본다면

사내 행사 퀴즈나 교육용 미니게임을 만들 때, 기획안을 에이전트에 넘기고 기본 게임의 캐릭터와 문구만 바꾸는 식을 떠올릴 수 있다.

가져갈 점

빈 화면에서 시작시키지 않고 잘 만든 기본 틀 25종을 먼저 주면 에이전트의 결과가 안정된다. 보고서 양식도 같은 방식으로 준비한다.

조심할 점

라이선스를 확인하지 못했다. 설치에는 개발 환경이 필요해 비개발자에게는 문턱이 높다. 수익화 문구는 소개글의 주장이다.
