AI 테스터 20대를 가상 휴대폰에 풀어 앱 버그를 찾는 저장소

GitHub Actions테스트 에이전트

mobile-agent-testers는 클로드 코드 에이전트가 휴대폰 20대에서 앱을 직접 써 보고 버그 보고서를 쓰게 한다. LocalSend 앱에서는 46건을 찾았다.

저장소 작성자는 에이전트마다 가상 아이폰이나 안드로이드 기기를 하나씩 주고, 페르소나(가상의 사용자 설정)대로 앱을 쓰게 했다. 에이전트는 화면 캡처를 붙인 버그 보고서를 쓴다. 작성자 설명으로는 LocalSend 20대 실행에 69분, 모델 사용료 4.62달러가 들었다.

왜 지금

깃허브 일일 증가분이 448개로 이날 목록에서 상위권이었다. 테스트 스크립트 없이 에이전트가 앱을 써 보게 하는 방식이 관심을 끈 것으로 보인다.

내 일에 써 본다면

새 사내 양식이나 신청 화면을 배포하기 전에, 글씨를 크게 키운 사람이나 외국어 사용자의 입장에서 써 보게 하는 방식으로 응용할 수 있다. 사람이 놓치는 막힘을 먼저 찾는 역할이다.

가져갈 점

정해진 시나리오 대신 사용자 유형을 정해 주고 써 보게 하면 아무도 생각 못 한 문제가 나온다. 이 저장소에서는 46건 중 34건이 접근성과 무관한 문제였다.

조심할 점

작성자가 직접 밝힌 수치이며 독립 검증은 확인하지 못했다. 라이선스는 본문에서 확인하지 못했으니 쓰기 전에 저장소에서 보아야 한다. 결과는 모델의 화면 해석 능력에 좌우된다.
