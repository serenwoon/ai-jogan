내 컴퓨터에서 도는 AI 봇 팀, 위험한 단계는 승인을 받는다

Apache-2.0데스크톱 에이전트MCP

PiBot은 역할을 가진 AI 봇 여러 개가 내 PC에서 파일을 고치고 명령을 실행하는 데스크톱 앱이다. 모든 위험한 단계는 사용자 승인을 기다린다.

PiBot은 개발자·연구자·작문가 같은 역할을 준 봇을 만들어 단체 대화방에 넣는 앱이다. 조정 봇이 계획을 짜면 사용자가 확인한 뒤 실행하고, 봇은 사용자가 정한 폴더 안에서만 일한다. 대화와 파일은 내 컴퓨터에 남고, 승인·명령 기록은 감사 로그에 쌓인다.

왜 지금

에이전트에게 업무를 맡기되 통제를 어떻게 붙일지가 올해 화두다. 이 앱은 승인, 샌드박스, 감사 로그를 처음부터 기본 구조로 넣었다. 수집 시점에 별 605개를 얻었다.

내 일에 써 본다면

매주 월요일 폴더에 쌓이는 회의 메모를 정해진 시간에 정리하게 하는 루틴을 걸어 두는 식이다. 파일 변경 목록을 보고 승인 버튼을 누르는 사람은 여전히 나다.

가져갈 점

자동화는 승인 지점을 먼저 설계하고 범위를 넓힌다. 폴더 제한, 실행 전 승인, 기록 남기기 세 가지는 어떤 도구에도 요구할 만하다.

조심할 점

공개 설명만 읽었고 직접 설치해 보지는 않았다. 쓰는 모델 제공업체에는 입력한 내용이 전달된다. 설치 파일은 공식 사이트에서만 받아야 한다.
