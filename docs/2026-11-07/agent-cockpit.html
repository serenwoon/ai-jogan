AI 연구 에이전트의 모든 주장에 근거 기록을 묶는 도구가 나왔다

MCP 서버라이선스 미확인

Agent Cockpit은 AI가 낸 결과가 어떤 실행과 코드에서 나왔는지 한 화면에 잇는다. 근거가 바뀌면 의존하는 카드가 붉게 바뀐다. 별 400개.

Agent Cockpit은 연구를 맡은 AI 에이전트가 계획, 실험 실행, 주장, 의존한 코드를 같은 화이트보드에 올리게 하는 로컬 도구다. 주장은 기록된 실행이 실제로 쓴 값만 근거로 삼는다. MCP는 AI 도구가 외부 프로그램과 연결되는 공통 규격이다.

왜 지금

AI 에이전트에게 며칠씩 일을 맡기는 팀이 늘면서, 검증된 결과가 슬며시 틀어지는 문제가 잦아졌다. 이 저장소는 그 점검을 규칙으로 기계에 넘긴다.

내 일에 써 본다면

분기 실적 보고서 초안을 AI에게 맡겼다면, 숫자마다 원본 파일과 셀 위치를 적게 한다. 원본이 바뀌면 그 숫자를 다시 확인 대상으로 돌리는 방식이다. 이 도구는 코드 저장소 기준이라 사무 문서에는 원리만 빌린다.

가져갈 점

AI의 결과물은 결과 자체보다 근거가 바뀌었는지가 더 중요하다. 근거를 해시(내용 지문)로 묶어 두면 되돌렸을 때 신뢰도 되살아난다.

조심할 점

설치에는 Node.js 22.13 이상과 git이 필요하고 개발자용이다. 라이선스는 확인하지 못했다. 점검이 LLM 없이 규칙으로 돌아간다는 것은 저장소 설명이다.
