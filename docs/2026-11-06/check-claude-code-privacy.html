클로드 코드 버전을 확인하고 개인정보 차단 기능을 점검한다

개인정보클로드 코드

클로드 코드가 웹 검색 중 이용자 이메일을 외부 사이트에 넘겼다는 신고가 나왔다. 2.1.317 이후 버전의 차단 기능을 10분 안에 확인한다.

한 이용자가 GitHub에 클로드 코드가 웹 검색 때 자신의 이메일 주소를 접속 정보(User-Agent)에 실어 보냈다고 신고했다. 이후 스팸 메일이 하루 수십 통 온다는 주장이다. 앤트로픽 담당자는 위키백과처럼 연락처 표기를 요구하는 사이트에서 모델이 스스로 주소를 넣은 것이라고 설명했다.

왜 지금

신고가 5일 올라오자 HN에서 빠르게 퍼졌다. AI가 사용자 대신 웹을 돌아다니는 시대에, 사용자 정보가 어디까지 나가는지 묻는 사례다.

내 일에 써 본다면

터미널에서 claude --version으로 버전을 본다. 이어서 플러그인 목록(/plugins)에서 cc-plugin-privacy가 켜져 있는지 확인한다. 팀에서 AI 도구를 쓴다면 업무용 계정 이메일을 도구 설정에 어디까지 넣었는지도 이 기회에 점검한다.

가져갈 점

AI 도구에 넣은 개인 정보는 모델의 판단에 따라 밖으로 나갈 수 있다. 꼭 필요하지 않은 정보는 처음부터 넣지 않는다.

조심할 점

앤트로픽 설명으로는 2.1.317 이후 이 차단 기능이 기본으로 켜진다. 다만 신고자는 2.1.318을 쓰는데도 목록에서 보이지 않는다고 답했고, 이 부분은 확인되지 않았다. 피해 주장도 신고자 한 명의 진술이다.
