오픈AI, 보안 점검 특화 모델 GPT-6 사이버를 승인 고객에게 열었다

보안OpenAI

오픈AI가 취약점 공격 성공률을 51% 끌어올린 보안 특화 모델을 내놨다. 승인받은 보안 전문가와 기업만 쓴다.

오픈AI가 5일(현지시간) 보안 취약점 점검에 특화한 GPT-6 사이버를 공개했다. 이 모델은 허가받은 작업에서 공격 코드를 쓰고 시험 환경에서 돌려 보며, 실패하면 다른 방법을 시도한다. 리눅스 커널 취약점 1724건을 재현해 948건에서 실제 작동하는 권한 상승 코드를 만들었다.

왜 지금

9월 나온 GPT-6 아스트라 위에 보안 훈련을 더한 모델이다. 팔로알토 네트웍스, 시스코, 센티넬원 같은 보안 업체가 이미 연구에 쓰고 있어, AI가 기업 보안 서비스의 일부로 들어오는 흐름을 보여 준다.

내 일에 써 본다면

사무직이 직접 쓸 모델은 아니다. 다만 사내 보안팀이나 외부 보안 업체가 점검 주기를 줄이겠다고 할 때, 점검 보고서가 몇 건을 찾았고 몇 건을 고쳤는지 물어볼 근거가 된다. 연말 정보보호 점검 보고서를 받아 볼 때 챙길 질문이다.

가져갈 점

강력한 AI일수록 쓰는 사람의 신원과 작업 범위부터 확인한다. 업무에 AI를 붙일 때도 누가 어디까지 맡기는지부터 정해야 한다.

조심할 점

수치는 오픈AI와 외부 평가사 발표를 AI타임스가 옮긴 것이다. 일부 평가에서는 범용 모델 GPT-6 아스트라보다 낮았고, 독립 기관의 종합 평가는 아직 확인되지 않았다.
