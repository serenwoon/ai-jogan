모델 컨텍스트 프로토콜(MCP)

AI 앱이 외부 도구와 자료에 접속하는 방법을 정한 공개 규격이다. 서버가 할 수 있는 일을 알리면 앱이 대신 호출한다.

MCP는 클로드, 커서, 챗GPT 같은 AI 앱이 외부 도구와 자료를 쓰도록 만든 공개 표준이다. 도구를 내놓는 작은 프로그램이 서버이고, AI 앱이 호스트다. 모델은 무엇을 쓸지 정할 뿐 서버와 직접 통신하지 않는다.

왜 지금

오늘 HN에 MCP를 그림으로 풀어 주는 안내 사이트가 올라왔다. 깃허브 인기 목록에서도 MCP 서버가 계속 보인다.

내 일에 써 본다면

회사 문서함이나 일정표를 AI 앱에 연결한다는 말이 나오면 사실상 MCP 서버를 하나 붙인다는 뜻이다. 도입 회의에서 서버가 어떤 권한을 가지는지 묻는 질문의 기준이 된다.

가져갈 점

AI가 직접 파일을 여는 것이 아니라 앱이 서버를 호출해 결과를 돌려준다. 통제는 서버에 어떤 권한을 주느냐에서 시작한다.

조심할 점

안내 사이트는 개인이 만든 학습 자료로 보이며 공식 문서가 아니다. 확보한 본문이 짧아 세부 내용은 확인하지 못했다.
