구글 크롬 팀 주도로, 코딩 에이전트의 낡은 웹 코드를 바로잡는 스킬이 나왔다

스킬라이선스 미확인

모던 웹 가이던스는 코딩 에이전트가 2019년식 자바스크립트 대신 최신 웹 기능을 쓰도록 안내하는 스킬이다. 활용 사례 203개를 담았다.

크롬, 엣지, 파이어폭스, MDN 팀이 함께 관리하는 스킬 모음이다. 에이전트가 웹 화면을 만들 때 최신 브라우저 기능과 호환성 정보를 맥락에 넣어 준다. 개발자가 쓰는 명령어로 설치하고 검색한다.

왜 지금

AI는 학습 자료에 옛 코드가 많아 낡은 방식을 자꾸 쓴다. 에이전트가 만든 코드의 질이 학습 시점에 묶인다는 문제의식에서 나왔고, 해커뉴스에서 화제가 됐다.

내 일에 써 본다면

사내 신청 양식이나 간단한 안내 페이지를 AI에게 맡길 때, 접근성과 성능 기준을 따로 적어 주는 대신 이런 지침 묶음을 붙여 둔다. 한 번 정리한 기준이 매번 재사용된다.

가져갈 점

모델이 모르는 최신 지식은 지침 파일로 공급한다. 모델에게 다 묻기보다 믿을 만한 기준 문서를 곁에 두는 편이 낫다.

조심할 점

개발자 대상 도구다. 라이선스는 수집된 본문에서 확인하지 못했다. 성능 개선 효과는 운영팀이 올린 평가 결과를 직접 보지 못해 검증하지 못했다.
