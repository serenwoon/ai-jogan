노션 AI에 붙여 넣은 비밀번호가 있는지 10분 안에 점검한다

보안노션

노션은 협력사 파이어웍스 AI의 보안 사고가 전체 작업공간의 1% 미만에 영향을 줬다고 알렸다. 연락받지 않았다면 조치할 것은 없지만, 대화 내용 점검은 습관이 된다.

노션은 협력사 파이어웍스 AI에서 보안 사고가 났고 작업공간의 1% 미만이 영향을 받았다고 공지했다. 피해 작업공간에는 노션 측이 직접 연락했다. 노출된 것은 AI와 나눈 대화 기록이다.

왜 지금

노션은 3일부로 파이어웍스와의 연결을 끊고 그쪽 데이터를 지웠다고 밝혔다. 조사는 진행 중이다. AI 기능이 외부 업체를 거쳐 돌아간다는 점이 드러난 사건이다.

내 일에 써 본다면

먼저 작업공간 관리자는 사이드바의 보안 사고 검토 메뉴를 열어 본다. 데스크톱 브라우저에서만 열린다. 팀원은 본인 대화에 비밀번호나 API 키를 붙여 넣은 적이 없는지 훑는다. 있다면 바로 바꾼다.

가져갈 점

AI 대화창에는 비밀번호와 접속 키를 넣지 않는다. 넣었다면 노출된 것으로 보고 바꾼다는 노션의 권고가 그대로 규칙이 된다.

조심할 점

내 작업공간이 피해 대상인지는 노션의 연락과 메뉴로만 확인된다. 회의록 기능 자료는 대화에 입력으로 쓰지 않았다면 영향이 없었다는 것이 회사 설명이다. 조사 결과는 달라질 수 있다.
