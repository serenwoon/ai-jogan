PDF와 스크린샷 속 글자까지 내 컴퓨터에서 찾는 무료 검색기

MITMCP 서버

kensaku는 파일 이름뿐 아니라 문서 본문과 이미지 속 글자를 찾는 MIT 라이선스 앱이다. 약 10만 개 파일 이름을 몇 밀리초에 찾는다.

kensaku는 PDF, 워드, 엑셀, 파워포인트 같은 문서 본문과 이미지 속 글자를 인식해 한 번에 검색하는 앱이다. 윈도·맥·리눅스에서 쓰며 한글 검색도 지원한다. 색인은 내 컴퓨터 안에만 두고 계정과 원격 전송이 없다고 소개한다.

왜 지금

AI 에이전트가 내 파일을 읽게 하려는 수요가 늘면서, 읽기 전용 MCP로 같은 색인을 에이전트에 열어 주는 기능이 붙었다. MCP는 AI가 외부 도구를 쓰도록 하는 연결 규격이다.

내 일에 써 본다면

지난달 회의 때 받은 견적서가 어디 있는지 이름이 기억나지 않을 때, 내용 일부나 지난주 스크린샷 같은 말로 찾을 수 있다.

가져갈 점

에이전트에게 파일을 열어 줄 때는 읽기 전용 색인 하나만 연결하는 방식이 안전하다.

조심할 점

빌드에 코드 서명이 없어 첫 실행 때 운영체제 경고가 뜬다. 속도 수치는 개발자가 밝힌 것이며 직접 재현하지 못했다.
