AI가 깨끗한 윈도 PC를 빌려 앱을 시험하게 해 주는 도구

MCP 서버라이선스 미확인

sandbox-mcp는 윈도 샌드박스를 켜 앱을 설치·조작하고 증거를 남긴 뒤 PC를 지운다. 측정된 시험은 30초 안팎이었다.

sandbox-mcp는 일회용 윈도 11 환경을 띄워 앱을 배포하고, 화면 조작을 자동으로 하고, 충돌 기록을 모은 뒤 환경을 지우는 도구다. 명령줄로 바로 쓸 수 있고, AI 도구와 잇는 MCP 어댑터는 선택이다. MCP는 AI가 외부 도구를 부르는 공통 규격을 가리킨다.

왜 지금

AI 에이전트에게 컴퓨터를 맡기는 일이 늘면서, 실제 PC를 건드리지 않고 시험할 격리 공간이 필요해졌다.

내 일에 써 본다면

사내 엑셀 매크로나 설치 파일을 동료에게 배포하기 전, 깨끗한 PC에서 한 번 돌려 볼 때 쓴다. 저장소 예시에서는 개발 PC에서 되던 프로그램이 빈 PC에서 필수 구성요소 누락으로 실패했고, 설치 후 통과했다.

가져갈 점

내 PC에서 되는 것과 남의 PC에서 되는 것은 다르다. 시험은 늘 빈 환경에서 하고, 결과는 화면과 로그로 남겨 두자.

조심할 점

윈도 샌드박스가 있는 PC에서만 돈다. 라이선스는 수집 본문에서 확인하지 못했다. 시간 수치는 저장소 작성자의 측정값이다.
