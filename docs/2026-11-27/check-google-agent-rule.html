구글 업무 자동화 스크립트가 새 규정 대상인지 점검하기

점검

구글이 2027년 2월 1일부터 AI 에이전트의 워크스페이스 접근을 MCP 서버로 제한한다. 쓰는 자동화가 해당하는지 10분이면 가려낼 수 있다.

구글은 24일 워크스페이스용 MCP 서버 8개를 정식 출시하고 API 약관에 새 조항을 넣었다. 2027년 2월 1일부터 AI 에이전트이거나 AI가 구동하는 도구는 지메일, 드라이브, 캘린더에 이 서버로만 접근해야 한다. 지메일 서버는 메일 검색, 읽기, 초안 작성은 되지만 발송과 답장은 파트너 전용이다.

왜 지금

시행까지 약 두 달이 남았다. 약관은 AI가 연결된 도구의 접근 방식을 바꾸라고 요구한다.

내 일에 써 본다면

먼저 메일 요약이나 일정 정리에 쓰는 자동화 목록을 적는다. 각각 AI 모델이 끼는지 가른다. AI가 낀 것은 구글 계정 관리자에게 시행일 이후 접근 경로를 묻는다. 매일 밤 도는 백업처럼 AI 없는 스크립트는 영향이 없다고 구글이 밝혔다.

가져갈 점

AI를 끼운 자동화는 도구 하나가 아니라 약관 대상이 된다. 목록을 먼저 만들어 두면 대응이 빠르다.

조심할 점

출처는 외부 기술 매체 분석이다. 개인 스크립트까지 포함되는지는 구글이 밝히지 않았다고 한다. 최종 판단은 구글 약관 원문으로 확인한다.
